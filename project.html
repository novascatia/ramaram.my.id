project-heiakim

project-heiakim adalah project yang berisi 3 bagian utama, yaitu bot discord moderation, bot discord music, dan server minecraft java yang digunakan untuk server discord "heiakim #alterpop".

server minecraft menggunakan minecraft java v.26.2 dengan beberapa plugin seperti floodgate, spark, dan plugin lainnya. server ini juga menggunakan geyser untuk memungkinkan player minecraft bedrock (pocket edition) bermain di server yang sama dengan player java (crossplay). untuk koneksi dari luar jaringan, server menggunakan playit agar bisa dimainkan bersama.

bot discord yang dibuat merupakan custom bot dengan fitur-fitur moderation seperti welcoming dan moderation ringan, mirip dengan bot discord pada umumnya. bot music juga merupakan custom bot dengan fitur dasar music bot seperti play music dan mengatur lagu yang sedang diputar.

project-heiakim hosted melalui termux menggunakan hp lama yang sudah tidak digunakan, sehingga tidak membutuhkan biaya hosting dan maintenance.
